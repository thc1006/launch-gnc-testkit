# Security policy

## Supported versions

Only the latest release is supported during the alpha phase.

## Reporting

Report vulnerabilities privately to the repository maintainers before publishing an
issue. Do not include secrets, restricted technical data, or private flight logs in a
public report.

## Scope boundaries

This project validates simulation artifacts. It is not flight-qualified and must not
be used as the sole assurance mechanism for a real vehicle. The project does not
accept classified material, export-controlled technical data, proprietary vehicle
parameters submitted without authorization, or weapon-specific operational datasets.
